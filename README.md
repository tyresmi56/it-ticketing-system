## Security Note
All database queries use parameterized statements (`?` placeholders)
rather than directly inserting user input into SQL strings. This
prevents **SQL injection**, a common attack where malicious input is
used to manipulate or damage a database.

## Why This Matters
Ticket/case tracking is a core workflow in IT support and help desk
roles. Building this system demonstrates the ability to translate a
familiar business process into working, secure software — combining
practical IT support experience with hands-on technical skill.
